# ns-builds

Weekend prototype loop.

- `IDEAS.md` — the backlog. Add ideas, star priorities.
- `prototypes/<slug>/` — one folder per build, each with its own README (what it is, how to run, next steps).
- `LOG.md` — one line per weekend run.

Every Saturday morning a scheduled task picks the top todo idea (⭐ first, then top of list), builds a working prototype here, updates IDEAS.md, and sends a short phone-friendly summary.
