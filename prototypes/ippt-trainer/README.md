# IPPT Trainer

Phone-first IPPT progress tracker. Log push-ups, sit-ups and 2.4 km sessions; see an estimated score, award band, and the cheapest way to reach your target.

## Open
Double-click `index.html` (works offline), or use the artifact link on your phone.

## What works
- Log sessions (any station can be left blank; score uses your latest value per station)
- Estimated score ring, award band (Gold 85+ / Silver 75+ / Pass 61+), countdown to your IPPT date
- "What gets you to target": cheapest next point + what one station alone would need
- Progress chart per station, personal bests, history with delete
- Export/import JSON to move data between phone and PC
- Sample data preloaded; clears when you log your first real session

## Important: scoring is an estimate
Only a few anchors are confirmed (age group 1: 60 push-ups = 25, 60 sit-ups = 25, 8:30 run = 50, 40 push-ups = 20). The rest is interpolated. Open Settings → Scoring table and paste values from the official CMPB/OneNS sheet for your age group to make it exact.
