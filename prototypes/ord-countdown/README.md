# ORD Countdown

Phone-first NS dashboard: days to ORD, % done, weeks grid, next milestone, projects shipped, skills learned, and a savings goal projected to ORD.

## Open
Double-click `index.html`, or use the artifact link on your phone.

## What works
- Countdown, progress bar, days served / weeks / months / weekends left
- Next milestone (25%, halfway, 1 year left, 75%, 100 days, last 30, ORD)
- Weeks-of-NS grid
- Projects shipped log with pace projection to ORD
- Skills with 3 levels (tap to bump)
- Savings goal: target, saved, monthly → on track / short and $/month needed
- Copy/paste data to move between devices

Defaults: enlistment 1 Oct 2026, ORD 1 Oct 2028. Change both in Settings.
